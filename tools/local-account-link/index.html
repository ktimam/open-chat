A local passkey.

This page tests linking a localhost passkey to your existing official OpenChat account. It is not the full chat client.

Linking changes your real OpenChat account by adding a sign-in credential. It does not create an account or send chat messages. The local passkey remains linked until you remove it in official OpenChat’s account settings.

1. Verify the account

In official OpenChat, open your profile/account settings and generate an account-linking code. Enter it here—not in a chat.

Verification consumes the code. If the account name is wrong, stop and obtain a fresh code.

Enter your username and a fresh official code above.

2. Review and link

No account verified.

Passkey scope: localhost. Backend: official OpenChat.

3. Test a fresh sign-in

This discards the temporary session and requests a new passkey assertion. The resulting user ID and OpenChat principal must match.

Choose the existing localhost test passkey in the picker. A different key is rejected; this does not create or link a key.

After linking, this checks the saved localhost passkey with a new sign-in.

Diagnostic only: uses the existing key with a random challenge. No OpenChat call, new key, or account change.

Only public credential details and the expected account identifiers are saved locally for reload testing. No private key, code or session token is saved.
